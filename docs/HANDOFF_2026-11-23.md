# 공용 저장소 인계 정리 (2026-11-23)

세 파트(게임·파이프라인·서버)를 공용 저장소 하나로 합친 뒤, 각 담당자에게 넘기는 내용입니다. 파트별로 **무엇이 바뀌었는지, 어디를 보면 되는지, 무엇이 남았는지**를 적었습니다. 각 담당자의 AI 코딩 에이전트에게도 이 문서와 파트별 변경 구현서를 먼저 읽히면 됩니다.

### 모든 담당자가 지킬 것

- `.env`, API 키, 비밀번호는 절대 커밋하지 않습니다(루트 `.gitignore`에 등록됨).
- 파트 브랜치에서 작업하고 PR로 `main`에 합칩니다. `main`에 강제 push(force push)는 하지 않습니다.
- 다른 파트 폴더를 고쳐야 하면 그 파트 담당자와 먼저 이야기합니다. 이벤트 형식은 `pipeline/contract.py`가 기준입니다.
- 게임 원본 저장소의 GitHub 기록에 Groq API 키가 남아 있습니다. **키를 폐기**해야 합니다(공용 저장소 기록에서는 지웠음).
